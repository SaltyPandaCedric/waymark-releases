Waymark

A companion app for World of Warcraft: Forever

Waymark runs next to the game and shows live data from it. It installs its own addon and keeps itself up to date.

Version 0.2.1 · released 8 November 2026 · release notes and all files

Windows Your system

For Windows 10 and 11, 64-bit. Installs for your user only, no admin rights needed.

Download for Windows Waymark-Setup-0.2.1.exe · 117 MB
  1. Run the installer.
  2. If Windows says "Windows protected your PC", choose "More info", then "Run anyway". Waymark isn't code signed yet. Updates don't show this again.

Linux and Steam Deck Your system

An AppImage for 64-bit Linux. Runs on most distributions and in the Steam Deck's desktop mode.

Download for Linux Waymark-0.2.1-x86_64.AppImage · 122 MB
  1. Mark the file as executable: chmod +x Waymark-*.AppImage, or Properties > Permissions in your file manager.
  2. Start it. Keep it in a folder you can write to, so it can update itself.

Good to know

  • Updates itselfInstalled apps download new versions in the background and update the addon with them.
  • Reads, never writesWaymark only reads the game's log file. It never sends anything into the game.
  • Works without a serverYour own characters work right away. A server is only needed to see friends' characters.
